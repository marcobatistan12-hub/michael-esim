# MICHAEL ESIM - Conectividade Global

Um site moderno e profissional para venda de planos de eSIM com interface intuitiva e checkout integrado com WhatsApp.

## 🚀 Características

- **Catálogo de Planos**: 4 planos diferentes de eSIM com dados variados
- **Sistema de Login/Cadastro**: Autenticação simples com localStorage
- **Checkout Inteligente**: Fluxo de compra em 2 etapas
- **Integração WhatsApp**: Redirecionamento para WhatsApp no pagamento
- **Design Responsivo**: Totalmente adaptado para mobile, tablet e desktop
- **Tema Verde Escuro**: Interface moderna e profissional
- **Suporte 24/7**: Link de WhatsApp em destaque no site

## 📋 Planos Disponíveis

1. **Plano Básico** - 5GB por R$ 19,90
2. **Plano Popular** - 15GB por R$ 49,90 (Mais Popular)
3. **Plano Premium** - 50GB por R$ 99,90
4. **Plano Ultra** - 100GB por R$ 179,90

## 🛠️ Tecnologias

- **React 18** - Framework UI
- **Vite** - Build tool
- **CSS3** - Estilização
- **Lucide React** - Ícones

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build
```

## 🌐 Deploy

### GitHub + Vercel

1. **Fazer push para GitHub**:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/seu-usuario/michael-esim.git
git push -u origin main
```

2. **Deploy no Vercel**:
- Acesse [vercel.com](https://vercel.com)
- Conecte seu repositório GitHub
- Vercel fará deploy automático a cada push

### Outras Opções

- **Netlify**: Conecte seu GitHub e faça deploy em 1 clique
- **GitHub Pages**: Use `npm run build` e faça push da pasta `dist`
